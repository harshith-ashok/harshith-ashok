## About

B.Tech CSE, SRM Institute of Science & Technology (2024–2028)

Research Intern at Madras Institute of Technology — search-and-rescue ground-node coordination (ESP32 ↔ Raspberry Pi over MQTT, FastAPI/WebSocket telemetry bridge)

Previously: Software Engineering Intern at IFF (International Flavors & Fragrances), LyncSpace Software Services

Focus areas: LLM-grounded systems, RAG pipelines, embedded automation, terminal-first tooling.

## What I Build

- **LLM decision assistants** — strict grounding, structured JSON output, minimal hallucination
- **Agentic pipelines** — LangGraph orchestration, retrieval-augmented reasoning, multi-agent task DAGs
- **Enterprise / ERP systems** — Frappe apps, custom workflows, relational data models
- **Automation & internal tools** — scraping, dashboards, DevOps/MLOps tooling
- **Embedded & IoT** — sensor networks, MQTT telemetry, edge displays, physical-world integrations
